# **App Name**: Campus Hub

## Core Features:

- User Authentication: Secure login and registration with college-specific customization. Admin roles have different level of access.
- Lost and Found: Allow students to post about lost items and claim found items. Send emails to the original poster if items were claimed or lost.
- Buy and Sell Marketplace: A platform for students to buy and sell items with other students.
- Borrow and Lend Section: Enable students to lend and borrow items from each other. It includes tools to compute total charges and notify both the borrower and the lender before the borrow time expires.
- Real-time Chat: Integrate a real-time chat feature for buyers/borrowers and sellers/lenders to communicate directly.

## Style Guidelines:

- Primary color: Soft blue (#A0D2EB) to represent trust and community.
- Background color: Light gray (#F5F5F5) to ensure readability and a clean look.
- Accent color: Muted orange (#F2BE22) for important actions and highlights.
- Headline font: 'Space Grotesk' sans-serif for a modern, slightly techy feel.
- Body font: 'Inter' sans-serif, which pairs well with 'Space Grotesk', is readable and neutral.
- Use clear, modern icons from a set like Material Design Icons to represent different categories and actions.
- Clean, grid-based layout with a focus on mobile responsiveness.
